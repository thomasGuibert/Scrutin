## Contexte

Le Code noir, ensemble d'ordonnances royales promulguées à partir de 1685, encadrait juridiquement l'esclavage dans les colonies françaises. Il n'a jamais été formellement abrogé, bien que l'esclavage ait été aboli en France en 1848.

## Action

Le texte propose l'abrogation formelle du Code noir.

## Résultat attendu

Le retrait officiel du Code noir du corpus juridique français.
