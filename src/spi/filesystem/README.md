# spi/filesystem

Implémentation v1 des interfaces déclarées par `domain` : lit les fichiers de dossiers (`content/dossiers/*.md`), la taxonomie déclarée, le fichier de référence des groupes et les données brutes AN (`data/raw/an/`). Seul endroit du code qui touche au système de fichiers.

Décidé dans [Schéma de données](https://github.com/thomasGuibert/Scrutin/issues/3) et [Architecture hexagonale](https://github.com/thomasGuibert/Scrutin/issues/4).
