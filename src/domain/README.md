# domain

Logique métier pure : calcul de Position, seuil Divisé, pondération par taux de participation, validation de la taxonomie. Aucune dépendance à Next.js ni au système de fichiers. Déclare les interfaces des deux côtés : celles que `api` expose, et celles que `spi` doit implémenter.

Décidé dans [Architecture hexagonale](https://github.com/thomasGuibert/Scrutin/issues/4) — voir aussi le [spec v1](https://github.com/thomasGuibert/Scrutin/issues/5).
